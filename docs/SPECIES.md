# Species names

Stored ids stay the rules keys. The sheet and the oath form show a player-facing name.

Aasimar is shown as Seraph. Tiefling is shown as Inferni. Both labels are homebrew. Inferni is a placeholder: change `INFERNI` in `src/lib/rules/species-names.ts` when the name is settled. Do not rename the database ids.

No light-background species art is implied by these names. No rules text is stored.
