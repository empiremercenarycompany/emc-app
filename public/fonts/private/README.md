# Private font

EMC holds a Corleone license for web and app use. The file stays out of this public repo.

Drop one of these here, then restart the app:

- `Corleone.woff2` (preferred)
- `Corleone.otf`
- `Corleone.ttf`

`@font-face` looks for those names. If none is present, headings use Barlow Condensed 800 through `--font-display`. Do not commit the font file.
